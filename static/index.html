后台设定

写法建议：背景设定 + 核心规则 + 玩家处境 + NPC 约束 + 胜利条件。也可以直接用左侧生成器。

玩家设定

普通字段直接填；不同游戏需要的战力、阵营、背包等字段，放到高级扩展 JSON。

动作是后台世界规则：由 NPC 对话、状态校验或 Agent 决策触发；运行台不直接暴露为通关按钮。

游戏运行台

先和 NPC 对话获得线索；移动、找人和观察只处理你明确输入的当前行动。

地点行动

“前往”只改变地点和可对话对象；“执行”用于观察、找人、查看线索，不直接完成剧情任务。
